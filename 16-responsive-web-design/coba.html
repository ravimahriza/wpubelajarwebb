Eksplorasi Unit Viewport Murni

Belajar cara kerja unit responsif modern: vw, vh, vmin, dan vmax secara terpisah sebelum memadukannya dengan fungsi kalkulasi.

Bagian 1: Contoh Kasus Viewport Width (vw) & Viewport Height (vh)

Unit vw (lebar) dan vh (tinggi) mengacu pada ukuran layar browser pengguna. 1vw setara dengan 1.100 (1%) dari lebar browser, sedangkan 1vh setara dengan 1/100 (1%) dari tinggi browser

Banner Responsif Vertikal

Tinggi Banner = 30vh 
.hero-banner {
    height: 30vh;
    width: 100%;
  }
height: 30vh

Tinggi Berbasis Persentase Layar

Mengunci tinggi banner sebesar 30% dari tinggi layar browser. Tinggi banner ini akan secara otomatis memanjang atau memendek mengikuti perubahan tinggi browser secara dinamis.

Petunjuk Uji Coba: Tarik browser Anda ke atas/bawah (ubah tinggi layar). Anda akan melihat tinggi banner di atas menyesuaikan secara instan.
