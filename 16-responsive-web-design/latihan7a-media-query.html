Eksplorasi Media Queries Dasar & Mobile-First

Menyesuaikan struktur layout dan gaya CSS secara bertahap menggunakan Breakpoints dan prinsip Mobile-First.

Bagian 1: Sintaks Dasar @media & Indikator Breakpoint

🔴 Mode Mobile (< 48em / 768px) — Style Default 🟠 Mode Tablet (≥ 48em / 768px) — @media (min-width: 48em) 🟢 Mode Desktop (≥ 64em / 1024px) — @media (min-width: 64em)
Sintaks @media (min-width) dengan Unit Relative 
/* Default Style (HP) */
.status-bar {
  background-color: #e11d48;
}

/* Tablet (≥ 768px) */
@media (min-width: 48em) {
  .status-bar {
    background-color: #d97706;
  }
}

/* Desktop (≥ 1024px) */
@media (min-width: 64em) {
  .status-bar {
    background-color: #059669;
  }
}

Cara Kerja Media Query

Aturan @media (min-width) akan mengaktifkan blok CSS di dalamnya hanya ketika lebar viewport browser telah mencapai batas minimal tersebut.

  • Mengapa Pakai Unit em? 48em sama dengan 768px (jika font dasar 16px). Menggunakan em di dalam media query menjaga tampilan tetap konsisten saat pengguna memperbesar (*zoom-in*) ukuran teks browser.
  • Respon Layar: Cobalah mengubah lebar browser Anda dari sempit ke lebar untuk melihat bar indikator berubah warna secara otomatis!
💡 Catatan Accessibility: Penggunaan em / rem pada Media Queries mencegah layout rusak ketika user mengaktifkan fitur *Text Zoom* di device mereka.

Bagian 2: Pendekatan Mobile-First

⚡ Performa Cepat

Layout ringan tanpa beban CSS desktop berlebih pada perangkat mobile.

📱 Mobile First

Menulis gaya 1 kolom terlebih dahulu tanpa deklarasi media query kompleks.

🖥️ Bertambah Bertahap

Menambahkan 2 dan 3 kolom seiring bertambahnya lebar layar browser.

Mobile-First Layout Cascade 
/* 1. Default Mobile (1 Kolom Vertikal) */
.feature-grid {
  display: flex;
  flex-direction: column;
  gap: 15px;
}

/* 2. Tablet (2 Kolom Grid) */
@media (min-width: 48em) {
  .feature-grid {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 3. Desktop (3 Kolom Grid) */
@media (min-width: 64em) {
  .feature-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

Mengapa Mobile-First Jauh Lebih Mudah?

Dalam pendekatan Mobile-First, kita menulis kode dasar untuk layar paling sederhana (HP) tanpa media query. Kita hanya menambahkan fitur dan kolom baru saat layar bertambah lebar:

  • Di HP (< 48em): Menampilkan 1 kolom tumpuk (fleksibel & alami untuk layar sentuh).
  • Di Tablet (≥ 48em): Berubah menjadi 2 kolom grid.
  • Di Desktop (≥ 64em): Berubah menjadi 3 kolom grid sejajar.
💡 Mobile First Principle: Kita tidak perlu "membongkar" atau mereset lagi desktop style yang kompleks saat membuka web di HP. Kode menjadi jauh lebih sedikit dan rapi!

Bagian 3: Perbandingan Metode Penulisan Media Query

Aturan Best Practice Penulisan

Perbandingan Desktop-First vs Mobile-First

🔴 Desktop-First (Sulit & Redundant)

/* Menulis desktop dulu, lalu membongkar di mobile */
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

@media (max-width: 768px) {
  .container {
    /* Harus mereset grid di HP */
    grid-template-columns: 1fr;
  }
}

🟢 Mobile-First (Clean & Scalable)

/* Menulis HP dulu (dasar), lalu menambahkan kolom */
.container {
  display: flex;
  flex-direction: column;
}

@media (min-width: 48em) {
  .container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
  }
}
🎯 Kesimpulan Utama: Dengan Mobile-First dan urutan min-width yang naik (*ascending order*), kode CSS lebih mudah dibaca, meminimalkan bug *override*, dan meningkatkan kecepatan *render* di browser mobile.
