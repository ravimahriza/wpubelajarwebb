Demo: Global Tokenization vs Component Isolation

Membandingkan pemetaan variabel global :root ke variabel lokal semantik komponen .btn.

1. Struktur Kode CSS

Berikut adalah pembagian jelas antara Global Tokens di :root dan Component Isolation pada .btn:

🔵 Global Tokens (:root) Didefinisikan sekali di :root untuk warna dasar, skala spasi, dan border-radius universal seluruh aplikasi. 
/* ==========================================================================
   GLOBAL DESIGN TOKENS (:root)
   Token terpusat untuk warna dasar, skala spasi, dan border-radius.
   ========================================================================== */
:root {
  /* Palette Warna Global (Global Color Tokens) */
  --color-primary: #3b82f6;
  --color-primary-dark: #1d4ed8;
  --color-danger: #ef4444;
  --color-danger-dark: #b91c1c;
  --color-success: #10b981;
  --color-success-dark: #047857;
  --color-white: #ffffff;

  /* Skala Spasi Global (Global Spacing Tokens) */
  --space-xs: 4px;
  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 24px;

  /* Skala Border Radius Global (Global Radius Tokens) */
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 16px;
  --radius-full: 9999px;
}
🟢 Component Isolation (.btn) Variabel lokal semantik yang mengisolasi komponen. Properti CSS (seperti background-color) ditulis HANYA SATU KALI! 
/* ==========================================================================
   COMPONENT ISOLATION (SEMANTIC ABSTRACTION) - TOMBOL (.btn)
   ========================================================================== */

/* 1. Kelas Utama: Properti CSS ditulis HANYA 1 KALI */
.btn {
  /* Variabel lokal semantik yang dipetakan dari global token */
  --btn-bg: var(--color-primary);
  --btn-bg-hover: var(--color-primary-dark);
  --btn-color: var(--color-white);
  --btn-border: var(--color-primary);
  --btn-padding: var(--space-sm) var(--space-md);
  --btn-radius: var(--radius-md);

  /* Aplikasi Properti CSS (Ditulis HANYA SATU KALI!) */
  background-color: var(--btn-bg);
  border: 1px solid var(--btn-border);
  color: var(--btn-color);
  padding: var(--btn-padding);
  border-radius: var(--btn-radius);
}

/* 2. State Hover: Cukup ganti nilai variabelnya! */
.btn:hover {
  --btn-bg: var(--btn-bg-hover);
  --btn-border: var(--btn-bg-hover);
}

/* 3. Variasi Warna: Cukup ganti nilai variabelnya tanpa rewrite properti! */
.btn-danger {
  --btn-bg: var(--color-danger);
  --btn-bg-hover: var(--color-danger-dark);
  --btn-border: var(--color-danger);
}

.btn-success {
  --btn-bg: var(--color-success);
  --btn-bg-hover: var(--color-success-dark);
  --btn-border: var(--color-success);
}

.btn-outline {
  --btn-bg: transparent;
  --btn-bg-hover: var(--color-primary);
  --btn-color: var(--color-primary);
  --btn-border: var(--color-primary);
}
.btn-outline:hover {
  --btn-color: var(--color-white);
}

/* 4. Modifier Ukuran: Cukup ganti variabel spasi & radius! */
.btn-lg {
  --btn-padding: var(--space-md) var(--space-lg);
  --btn-radius: var(--radius-lg);
}

2. Hasil Visual Variasi Tombol (.btn)

Semua tombol di bawah menggunakan kelas utama .btn. Perhatikan bahwa properti CSS seperti background-color, border, dan padding tidak ditulis ulang pada variasi warna maupun ukuran!
