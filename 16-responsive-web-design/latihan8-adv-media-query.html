Eksplorasi Advanced & Non-Viewport Media Queries

Mendeteksi Orientasi Layar, Skema Warna (Dark Mode), Sensitivitas Animasi (Reduced Motion), dan Perangkat Interaksi (Touch vs Mouse).

Bagian 1: Orientation Query (landscape vs portrait)

📱 Mode PORTRAIT (Tinggi Viewport > Lebar) 💻 Mode LANDSCAPE (Lebar Viewport > Tinggi)
Orientation Query 
@media (orientation: portrait) {
  .box {
    background-color: #0284c7;
  }
}

@media (orientation: landscape) {
  .box {
    background-color: #7c3aed;
  }
}

Cara Kerja Orientation Query

Browser membandingkan rasio aspect ratio antara lebar dan tinggi viewport:

  • portrait: Aktif ketika tinggi viewport lebih besar dari lebarnya (tampilan vertikal HP biasa).
  • landscape: Aktif ketika lebar viewport lebih besar dari tingginya (tampilan miring HP / monitor laptop).
💡 Catatan Penting: Orientation Query mendeteksi rasio aspect ratio *viewport browser*, bukan rotasi fisik HP dari akselerometer!

Bagian 2: Prefers Color Scheme (Dark Mode & Light Mode)

☀️ Mode Terang (Light Mode) Aktif 🌙 Mode Gelap (Dark Mode) Aktif

Warna otomatis menyesuaikan preferensi sistem operasi Anda.

Prefers Color Scheme 
:root {
  --bg-card: #ffffff;
  --text-main: #0f172a;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-card: #1e293b;
    --text-main: #f8fafc;
  }
}

Integrasi Dark Mode dengan CSS Variables

Mendeteksi setelan tema sistem operasi (Windows / macOS / Android / iOS) atau browser yang dipilih oleh pengguna:

  • Best Practice: Alih-alih menulis ulang seluruh selector CSS, cukup ubah (*override*) nilai CSS Variables di dalam `@media (prefers-color-scheme: dark)`.
  • Otomatis & Nyaman: Pengunjung tidak perlu mengklik tombol toggle manual jika mereka sudah menyetel mode malam di perangkat mereka.
💡 Uji Coba: Ubah setelan tema OS / browser Anda dari Light ke Dark Mode untuk melihat kartu di atas berganti warna secara langsung!

Bagian 3: Prefers Reduced Motion (Aksesibilitas Animasi)

Deteksi Animasi Aksesibilitas:
✨ Animasi Aktif (no-preference) ⏸️ Animasi Dimatikan (reduce)
Prefers Reduced Motion 
.element {
  animation: pulse 2s infinite;
}

@media (prefers-reduced-motion: reduce) {
  .element {
    animation: none;
    transition: none;
  }
}

Menghormati Sensitivitas Gerakan Pengguna

Mendeteksi jika pengguna mengaktifkan opsi "Reduce Motion" di setelan aksesibilitas OS mereka (misalnya pengguna yang rentan terhadap penyakit mabuk gerakan / *motion sickness*):

  • no-preference: Pengguna menyukai animasi dan efek gerakan mulus secara normal.
  • reduce: Matikan animasi yang intens, gerakan memutar, atau efek berdenyut berlebih demi kenyamanan mata dan kesehatan pengguna.
💡 Prinsip Aksesibilitas: Menghormati preferensi prefers-reduced-motion adalah standar wajib dalam pembuatan antarmuka web modern yang inklusif.

Bagian 4: Pointer & Hover Query (Layar Sentuh vs Mouse)

📱 Perangkat Layar Sentuh / Touchscreen (pointer: coarse)
🖱️ Perangkat Mouse Presisi (pointer: fine & hover: hover)
Pointer & Hover Queries 
/* Layar Sentuh (Jari HP) */
@media (pointer: coarse) {
  .btn {
    padding: 16px 28px; /* Touch target ≥ 48px */
  }
}

/* Desktop Mouse */
@media (hover: hover) and (pointer: fine) {
  .btn:hover {
    transform: translateY(-3px);
  }
}

Mengatasi Bug Double-Tap di Layar Sentuh

Di HP layar sentuh, tidak ada kursor melayang. Tap pertama sering dianggap sebagai `:hover` oleh browser mobile, menyebabkan bug tombol harus di-tap 2 kali!

  • pointer: coarse: Perangkat sentuh dengan penunjuk kurang presisi (jari). Berikan padding tombol lebih besar (aturan minimum 48px).
  • hover: hover: Hanya berikan efek `:hover` jika perangkat benar-benar memiliki kursor penunjuk nyata (mouse / trackpad).
💡 Solusi UX: Menggabungkan hover: hover dan pointer: fine memastikan efek hover hanya aktif di desktop dan bebas bug di HP!

Bagian 5: Ringkasan Fitur Media Queries Non-Viewport

Ringkasan Fitur Modern

Manfaat Media Queries Non-Viewport dalam RWD

🔴 Cara Lama (Hanya Berpatokan Lebar Layar)

/* Efek hover diaktifkan global tanpa cek device */
.button:hover {
  background-color: #2563eb;
}
/* Menimbulkan bug double-tap di HP touchscreen! */

🟢 Cara Modern (Adaptif & Inklusif)

/* Mengaktifkan hover HANYA di perangkat mouse */
@media (hover: hover) and (pointer: fine) {
  .button:hover {
    background-color: #2563eb;
  }
}
🎯 Kesimpulan Utama: Media Queries modern melampaui sekadar lebar layar. Dengan mendeteksi orientasi, preferensi skema warna (Dark Mode), preferensi animasi, dan jenis input pengguna, web kita menjadi jauh lebih cerdas, adaptif, dan ramah aksesibilitas.
