Demo: Variable Fragments & Media Query Override

Memecah properti kompleks menjadi fragmen variabel modular, lalu menimpa fragmen tersebut di Media Query tanpa menulis ulang selektor CSS.

1. Struktur Kode CSS

Berikut adalah contoh penggunaan Variable Fragments dan cara melakukan Media Query Override secara bersih & DRY:

1. HSL Color Fragments (--hue, --sat, --light) 
/* Deklarasi Komponen dengan Fragmen HSL (Mobile-First) */
.hsl-card {
  --hue: 210; /* Fragmen Hue (Default: Biru 210) */
  --sat: 85%;
  --light: 50%;

  /* Menggabungkan fragmen ke fungsi hsl() */
  background-color: hsl(var(--hue), var(--sat), 95%);
  border: 2px solid hsl(var(--hue), var(--sat), 80%);
}

/* Media Query Override: CUKUP TIMPA FRAGMEN --hue SAJA! */
@media (min-width: 48em) {
  .hsl-card {
    --hue: 160; /* Berubah otomatis jadi Hijau Emerald 160 tanpa re-write properti! */
  }
}
2. Linear Gradient Fragments (--grad-angle, --grad-hue) 
/* Deklarasi Komponen Hero Gradien */
.gradient-hero {
  --grad-angle: 135deg;
  --grad-hue-1: 220; /* Fragmen Warna 1 */
  --grad-hue-2: 260; /* Fragmen Warna 2 */

  background: linear-gradient(
    var(--grad-angle),
    hsl(var(--grad-hue-1), 85%, 55%),
    hsl(var(--grad-hue-2), 85%, 55%)
  );
}

/* Media Query Override: CUKUP TIMPA FRAGMEN ANGEL & HUE */
@media (min-width: 48em) {
  .gradient-hero {
    --grad-angle: 90deg;
    --grad-hue-1: 340; /* Pink */
    --grad-hue-2: 30;  /* Oranye */
  }
}
