Simulasi Masalah Scrollbar Layout Shift

Gunakan panel kontrol di bawah ini untuk melihat bagaimana kemunculan scrollbar vertikal menggeser letak navbar dan tulisan ini, serta bagaimana kita menstabilkannya.

Status Perbaikan: TIDAK AKTIF 
/* CSS Default Browser: */
html {
  scrollbar-gutter: auto; /* Ruang scrollbar TIDAK dipesan */
}

Ini adalah konten dasar halaman web. Halaman ini sangat pendek sehingga belum memiliki scrollbar vertikal di sebelah kanan. Silakan klik tombol "Toggle Konten Panjang" di atas. Perhatikan baik-baik teks navbar di bagian atas layar dan tepi kotak putih ini saat halaman memanjang dan memendek secara berulang.
