Demo: Reactive Properties & Media Feature Queries

Mendemonstrasikan reaktivitas CSS Variables yang secara otomatis mengubah tema, animasi, dan target sentuh saat dipadukan dengan Media Feature Queries.

1. Struktur Kode CSS

Berikut adalah contoh kode CSS yang memanfaatkan 3 Media Feature Queries untuk mengubah nilai variabel di :root secara reaktif:

1. System Dark Mode (@media (prefers-color-scheme: dark)) 
/* Mengubah tema warna seluruh website tanpa re-write selektor komponen */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-main: #0f172a;
    --card-bg: #1e293b;
    --text-main: #f8fafc;
    --border-color: #334155;
    --accent-color: #60a5fa;
  }
}

body {
  background-color: var(--bg-main, #f8fafc);
  color: var(--text-main, #0f172a);
}
2. Reduced Motion (@media (prefers-reduced-motion: reduce)) 
/* Mematikan transisi/animasi aplikasi bagi pengguna yang mudah mual */
@media (prefers-reduced-motion: reduce) {
  :root {
    --transition-speed: 0s;
    --animation-play: paused;
  }
}

.card {
  transition: transform var(--transition-speed, 0.3s) ease;
}
3. Touch Target (@media (pointer: coarse)) 
/* Menyesuaikan tinggi minimal tombol sentuh (Exaggerated: 60px di Layar Sentuh vs 36px di Mouse) */
@media (pointer: coarse) {
  :root {
    --min-touch-height: 60px;
  }
}

.touch-btn {
  height: var(--min-touch-height, 36px);
  min-height: var(--min-touch-height, 36px);
}
